1. 개인 접속키

Cloudflare의 APP_ACCESS_KEY와 같은 값을 입력하세요. 브라우저 세션에만 저장됩니다.

2. API 연결 점검

현재 실행 중인 Worker가 Cloudflare 변수/시크릿을 실제로 인식하는지 먼저 확인합니다.

Cloudflare 연결 문제 해결 보기

중요: Variables and Secrets에 값을 입력한 것만으로 끝나지 않습니다. 편집 화면에서 Deploy를 눌러 현재 Worker 버전에 반영해야 합니다.

APP_ACCESS_KEY, DART_API_KEY, ECOS_API_KEY, KIS_APP_KEY, KIS_APP_SECRET, KRX_AUTH_KEY는 모두 Secret 타입을 권장합니다.

이 버전은 keep_vars=true를 넣어 GitHub 자동배포가 대시보드의 Text 변수를 덮어쓰는 문제도 줄였습니다.

3. 종목 분석

종목코드 하나로 주가·수급·3개년 실적·4개 분기 실적·유보율·부채비율을 함께 확인합니다.

주가·수급·재무 데이터를 함께 불러오는 중입니다. 수 초 걸릴 수 있습니다.
