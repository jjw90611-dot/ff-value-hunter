# FF Value Hunter v0.6

산업의 흐름을 먼저 보고, 해당 산업의 기업을 재무·수급·가격 관점에서 검증하는 개인용 가치투자 스캐너입니다.
자동 매수/매도 기능과 주문 API는 포함하지 않습니다.

## v0.6 핵심 수정

### 1. 섹터 지속상승 점수 세분화
v0.5의 점수는 조건 충족 시 5~20점씩 더하는 계단식 방식이라 여러 섹터가 70점에 몰릴 수 있었습니다.
v0.6은 실제 퍼센트 값을 연속 점수로 변환해 소수점 1자리까지 표시합니다.

- 정배열·이격도: 25점
- MA20/60/120 기울기: 25점
- 20/60/120일 수익률: 30점
- 상승일 비율: 10점
- 최근 60일 최대낙폭 및 120일 범위 위치: 10점

등급은 S(90+), A+(82+), A(74+), B(66+), C(58+), D로 나눕니다.
기존 캐시를 재사용하지 않도록 섹터 캐시 키도 v6로 변경했습니다.

### 2. 건설업에 KCC·포스코퓨처엠 등이 섞이던 오류 수정
v0.5에서는 선택 업종코드를 종목 마스터의 대분류/중분류/소분류와 모두 비교하고 KRX 섹터 플래그도 OR 조건으로 섞었습니다.
그 때문에 서로 다른 분류체계의 숫자가 우연히 같거나 KRX 테마 플래그가 잡히면서 엉뚱한 종목이 관련주에 섞일 수 있었습니다.

v0.6은 STEP 1의 KIS 공식 업종지수와 종목 마스터의 **지수업종 대분류 코드가 정확히 같은 종목만** 관련기업으로 표시합니다.
중분류·소분류·KRX 테마 플래그는 공식 업종 목록과 섞지 않습니다.

### 3. 관련기업이 안 보이던 문제 보완
- 섹터를 바꿀 때 이전 섹터의 기업검색어를 자동 초기화합니다.
- 매칭 결과가 0건이면 단순 빈 화면 대신 선택한 업종명/업종코드를 보여줍니다.
- 기업 카드가 있으면 시가총액 순으로 먼저 보여주고, `매출·안정성 우량순 분석` 후 재무 점수로 재정렬합니다.

### 4. 기업 우량점수도 연속 점수화
기업 점수 역시 같은 점수 반복을 줄이기 위해 실제 수치의 차이를 반영합니다.

- 매출: 30점 (3년 CAGR + 상승 연속성)
- 영업이익: 20점 (흑자 지속 + 증가 + CAGR)
- 부채비율: 20점
- 유보율: 10점
- ROE: 10점
- 영업이익률: 10점

점수는 소수점 1자리까지 표시합니다.

### 5. Npay 증권 PC/모바일 자동 분기
- PC: `https://stock.naver.com/domestic/stock/종목코드/price`
- 모바일: `https://m.stock.naver.com/domestic/stock/종목코드/total`

브라우저/화면 크기를 기준으로 자동 선택합니다.

## KRX가 `활용승인 필요`로 뜨는 이유
`KRX_AUTH_KEY`가 Cloudflare에 존재하는 것과 특정 KRX API 서비스를 호출할 권한이 있는 것은 별개입니다.
KRX는 인증키 승인 후에도 원하는 API마다 `API 활용 신청 → 관리자 승인` 절차가 필요합니다.
현재 연결점검은 `유가증권 일별매매정보`를 호출하므로 이 서비스가 미승인/승인대기이면 HTTP 401이 납니다.

현재 FF Value Hunter의 섹터·기업 발굴 핵심은 KIS이므로 KRX 401은 핵심 기능을 막지 않습니다.

## 필요한 Cloudflare Secrets

```text
APP_ACCESS_KEY
DART_API_KEY
KIS_APP_KEY
KIS_APP_SECRET
KRX_AUTH_KEY
ECOS_API_KEY
```

기존 v0.5 값 그대로 사용합니다.

## 배포

1. ZIP을 풉니다.
2. 기존 GitHub 저장소의 파일을 v0.6 파일로 교체합니다.
3. Commit / Push 합니다.
4. Cloudflare Workers 자동배포가 완료될 때까지 기다립니다.
5. 기존 Runtime Variables and Secrets는 그대로 유지합니다.
6. 사이트에서 `섹터 불러오기 → 지속 상승 분석`을 다시 실행합니다. v6 캐시 키를 사용하므로 새 점수로 다시 계산됩니다.
