# FF Value Hunter v0.7

산업의 흐름을 먼저 보고, 해당 산업의 기업을 재무·수급·가격 관점에서 검증하는 개인용 가치투자 스캐너입니다.
자동 매수/매도 기능과 주문 API는 포함하지 않습니다.

## v0.7 핵심 수정

### 1. `업종코드 일치 기업 0개` 문제 구조 수정
기존 버전은 KIS `국내업종 구분별전체시세`를 `소속구분=0(전업종)`으로 받아 KRX/TMI/선물/채권혼합/스마트베타 등 **기업 업종이 아닌 지수**까지 STEP 1에 섞였습니다.
이 때문에 `KRX 보험(4015)`처럼 지수 차트는 존재하지만 종목 마스터의 지수업종 대분류와 직접 대응되지 않는 항목을 누르면 관련기업 0개가 나올 수 있었습니다.

v0.7은 다음 순서로 고쳤습니다.

1. KOSPI는 KIS `소속구분=3(산업별구분)`을 우선 조회
2. KOSDAQ도 우선 일반구분을 조회하되 산업 섹터가 부족하면 전업종 목록을 재조회
3. KIS 종목 마스터의 `지수업종 대분류 코드`가 실제로 존재하는 항목만 매핑
4. **관련기업이 1개 이상인 섹터만 STEP 1에 표시**
5. 선물/채권/TMI/스마트베타/기후지수/ETF·ETN 등은 자동 제외
6. `KRX 보험`, `KRX 건설`처럼 이름 자체가 KRX 섹터임이 명확한 경우에만 공식 KRX 섹터 플래그를 제한적으로 사용
7. 일반 `건설`, `보험`에는 KRX 테마 플래그를 절대 섞지 않음

따라서 사용자가 클릭할 수 있는 섹터는 서버에서 이미 **구성기업 존재 여부를 검증한 뒤** 내려갑니다.

### 2. 잘못된 관련주 혼입 방지
일반 산업은 반드시 KIS 업종코드 ↔ 종목마스터 `지수업종 대분류` 정확 일치만 사용합니다.
중분류·소분류·테마 플래그를 OR 조건으로 섞지 않습니다.

이로써 건설 섹터에 KCC·포스코퓨처엠처럼 다른 산업 기업이 섞이던 유형의 오류를 방지합니다.

### 3. 섹터 지속상승 점수 세분화
점수는 조건 충족 시 10점씩 더하는 계단식이 아니라 실제 퍼센트 기반 연속점수입니다.

- 정배열·이격도: 25점
- MA20/60/120 기울기: 25점
- 20/60/120일 수익률: 30점
- 상승일 비율: 10점
- 최근 60일 최대낙폭 및 120일 범위 위치: 10점

S(90+), A+(82+), A(74+), B(66+), C(58+), D로 나누고 소수점 1자리까지 표시합니다.
섹터 캐시는 v7 키를 사용하므로 이전 버전 결과가 섞이지 않습니다.

### 4. KRX를 실제 데이터원으로 사용
v0.7부터 KRX는 연결점검용으로만 두지 않습니다.

승인된 아래 API를 실제로 사용합니다.

- 유가증권 일별매매정보
- 코스닥 일별매매정보
- 유가증권 종목기본정보
- 코스닥 종목기본정보
- KOSPI 시리즈 일별시세정보
- KOSDAQ 시리즈 일별시세정보

활용 방식:

- 섹터 관련기업 카드에 KRX 공식 당일 등락률/시가총액을 보조 표시
- 기업 검색에 KRX 공식 영문 종목명을 결합
- KRX 6개 API 연결 상태를 개별 점검
- KIS가 산업/수급/재무를 담당하고 KRX가 전체 시장·상장종목·일별매매 검증을 담당

KRX 호출이 승인 시작 전, 휴일, 일시 장애 등으로 실패해도 핵심 산업→기업 흐름은 KIS 데이터로 계속 작동하도록 설계했습니다.

> KRX 이용현황의 사용기간 시작일이 미래라면 승인 상태여도 시작일 전까지 HTTP 401이 날 수 있습니다.

### 5. 기업 우량점수 연속 점수화

- 매출: 30점 (3년 CAGR + 상승 연속성)
- 영업이익: 20점 (흑자 지속 + 증가 + CAGR)
- 부채비율: 20점
- 유보율: 10점
- ROE: 10점
- 영업이익률: 10점

점수는 소수점 1자리까지 표시합니다.

### 6. Npay 증권 PC/모바일 자동 분기

- PC: `https://stock.naver.com/domestic/stock/종목코드/price`
- 모바일: `https://m.stock.naver.com/domestic/stock/종목코드/total`


## 배포

1. ZIP을 풉니다.
2. 기존 GitHub 저장소의 파일을 v0.7 파일로 전부 교체합니다.
3. Commit / Push 합니다.
4. Cloudflare Workers 자동배포가 완료될 때까지 기다립니다.
5. 기존 Runtime Variables and Secrets는 그대로 유지합니다.
6. 사이트에서 `섹터 불러오기 → 지속 상승 분석`을 다시 실행합니다.
