# FF Value Hunter v0.4

산업을 먼저 고르고, 그 산업 안에서 재무적으로 좋은 기업을 찾는 개인용 가치투자 스캐너입니다.

> 자동 매수/매도 기능은 없습니다. 주문 API를 사용하지 않습니다.

## v0.4 핵심 흐름

1. KIS의 KOSPI/KOSDAQ 업종 목록을 불러옵니다.
2. 업종별 일봉으로 20/60/120일 이동평균, 기울기, 20/60/120일 수익률을 계산합니다.
3. 지속 상승 점수가 높은 업종을 먼저 보여줍니다.
4. 업종을 누르면 한국투자증권 공식 KOSPI/KOSDAQ 종목 마스터를 이용해 관련기업을 표시합니다.
5. `매출·안정성 우량순 분석`을 누르면 시가총액 상위 최대 60개를 대상으로 최근 3개년 매출/영업이익과 부채비율·유보율·ROE를 조회해 재정렬합니다.
6. 기업별 `Npay 차트`는 `https://finance.naver.com/item/main.nhn?code=종목코드`로 새 탭에서 엽니다.
7. `FF 상세`에서는 외국인·기관 수급, 차트, 최근 3년/4분기 실적을 추가 확인합니다.

## 우량점수 v0.4

- 최근 3개년 매출 우상향: 최대 30
- 영업이익 안정성/증가: 최대 20
- 부채비율: 최대 20 (150% 미만을 FF 기준으로 우대)
- 유보율: 최대 10
- ROE: 최대 10
- 최근 영업이익률: 최대 10

현재 점수는 기업의 질(Quality)을 우선 정렬하기 위한 1차 점수입니다. 이후 버전에서 동일 섹터 대비 저평가(Value)와 외국인·기관 지속매집(Supply)을 결합할 예정입니다.

## 필요한 Cloudflare Secrets

기존 v0.3과 동일합니다.

```text
APP_ACCESS_KEY
DART_API_KEY
KIS_APP_KEY
KIS_APP_SECRET
KRX_AUTH_KEY
ECOS_API_KEY
```

산업/섹터와 기업 선별의 핵심 API는 `KIS_APP_KEY`, `KIS_APP_SECRET`입니다. DART/KRX/ECOS에 문제가 있어도 핵심 산업→기업 발굴 흐름은 KIS가 정상이라면 사용할 수 있도록 구성했습니다.

## 배포

1. 이 ZIP을 풀어 기존 GitHub 저장소 파일을 v0.4 파일로 교체합니다.
2. GitHub에 commit/push 합니다.
3. Cloudflare Workers Builds가 새 commit을 배포하는지 확인합니다.
4. 기존 Variables and Secrets는 그대로 유지합니다. `wrangler.jsonc`의 `keep_vars: true`가 Dashboard 변수 보존을 돕습니다.
5. 사이트에서 접속키 적용 → `섹터 불러오기` → `지속 상승 분석` 순서로 시작합니다.

KIS가 공식 배포하는 KOSPI/KOSDAQ 종목 마스터 ZIP은 Cloudflare Worker 내장 `DecompressionStream`으로 해제하므로 별도 런타임 패키지 의존성이 없습니다.

## KIS 호출제한 대응

- OAuth 토큰 캐시/재사용
- KIS 호출 직렬화
- 호출 간 최소 간격
- rate-limit 응답 재시도
- 섹터 장기추세 결과 4시간 캐시
- 종목 마스터 결과 12시간 캐시

업종 전체 장기분석은 일부러 순차 실행합니다. 첫 분석은 시간이 걸릴 수 있지만 캐시가 쌓이면 다시 볼 때 훨씬 빨라집니다.

## 데이터 원칙

주달의 `테마 목록 → 테마 클릭 → 관련주` UX는 참고하되, 서비스의 핵심 데이터는 주달 화면 크롤링에 의존하지 않습니다. 업종/종목 관계는 KIS 공식 업종 API와 KIS 공식 종목 마스터를 우선 사용합니다. 이렇게 해야 외부 HTML 변경으로 사이트 전체가 깨지는 위험을 줄일 수 있습니다.

v0.4는 테마성 종목 묶음보다 공식 업종/산업 분류를 먼저 제공합니다. 방산·로봇·변압기 등 더 세부적인 테마 레이어는 별도 데이터 소스를 검증한 뒤 추가하는 것이 안전합니다.
