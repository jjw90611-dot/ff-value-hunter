# FF Value Hunter v0.3

자동매수/자동매도 프로그램이 아니라, KIS/공시/시장 데이터를 모아 가치투자 후보를 검토하기 위한 개인용 분석기입니다.

## v0.3에서 고친 문제

1. **KIS 초당 거래건수 초과**
   - v0.2의 `Promise.all()` 병렬호출 제거
   - KIS 요청을 순차 처리하고 호출 간격을 둠
   - 초당 제한 응답이면 짧게 재시도
   - 일봉 차트 페이지 호출도 최대 2회로 축소

2. **KIS OAuth 1분당 1회**
   - Worker 메모리 + Cloudflare Cache API에 접근토큰을 저장해 재사용
   - 새 토큰을 매 분석마다 발급하지 않음
   - 직전에 v0.2에서 토큰을 발급했다면 v0.3 첫 실행은 60초 정도 기다린 뒤 한 번만 시도

3. **기업명/업종이 안 보이는 문제**
   - KIS `주식기본조회(search-stock-info)` 추가
   - 기업명, KOSPI/KOSDAQ, 업종 대/중/소분류, 표준산업분류, 결산월, 상장일 표시

4. **OpenDART 무한 리디렉션 및 키 노출**
   - 자동 리디렉션을 중단하고 오류페이지 이동을 감지
   - 화면 오류문에서 API 키/긴 인증값을 마스킹
   - DART가 실패해도 KIS 기업정보/주가/수급/재무 분석은 계속 작동

5. **연간 실적에 반기 값이 섞이는 문제**
   - KIS 기업정보의 결산월을 기준으로 연간값만 추출
   - 예: 12월 결산 기업은 2025.12 / 2024.12 / 2023.12 형태로 표시
   - 최근 공시 기준 안정성 수치와 연간 3개년 추세를 구분

## 배포

1. 이 ZIP을 풀고 기존 GitHub 저장소의 파일을 v0.3 파일로 교체합니다.
2. GitHub에 commit/push 합니다.
3. Cloudflare 배포가 Success가 될 때까지 기다립니다.
4. 기존 Secrets는 그대로 사용합니다.

필요 Secrets:

- `APP_ACCESS_KEY`
- `DART_API_KEY`
- `KIS_APP_KEY`
- `KIS_APP_SECRET`
- `KRX_AUTH_KEY`
- `ECOS_API_KEY`

실제 키를 GitHub 코드에 넣지 마세요.

## 첫 실행 순서

1. 배포 직후 KIS 토큰을 방금 발급한 상태라면 60초 정도 기다립니다.
2. `APP_ACCESS_KEY` 입력 → 적용
3. `전체 연결 점검`
4. KIS/ECOS가 정상인지 확인
5. KRX가 `확인필요`이면 KRX 사이트에서 해당 API의 **활용신청 승인**을 확인합니다.
6. DART가 `확인필요`이어도 종목분석은 진행할 수 있습니다.
7. 종목코드만 입력하고 분석 실행합니다. DART 기업고유번호는 선택입니다.

## KRX 401일 때

KRX는 인증키 발급과 개별 API 활용승인이 별도입니다. 최소한 아래 서비스를 활용신청/승인 상태로 만들어두는 것을 권장합니다.

- 유가증권 종목기본정보
- 코스닥 종목기본정보
- 유가증권 일별매매정보
- 코스닥 일별매매정보
- KOSPI 계열 일별시세
- KOSDAQ 계열 일별시세

v0.3 단일 종목 분석은 KIS 중심이라 KRX 401이어도 동작합니다. 전체시장 스캐너 단계에서 KRX를 본격 사용합니다.

## 화면 구성

기업을 분석하면 가장 위에 기업명/종목코드/시장/섹터를 표시합니다. 아래 상세영역은 기본적으로 닫혀 있고 눌러서 엽니다.

- 기업 · 시장 · 업종 정보
- 주가 차트 · MA20/60/120
- 외국인 · 기관 수급 상세
- 최근 3년 매출액 · 영업이익
- 최근 4개 분기 매출액 · 영업이익
- 안정성 · 유보율 · 부채비율
- DART 기업정보(기업고유번호를 입력한 경우)

## 보안 주의

API 오류 화면/캡처에 키가 노출되면 해당 키는 재발급 후 Cloudflare Secret을 교체하는 것을 권장합니다. v0.3부터 오류 메시지에 인증키가 그대로 출력되지 않도록 마스킹합니다.
