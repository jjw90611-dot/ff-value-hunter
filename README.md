# FF Value Hunter v0.8

산업을 먼저 고른 뒤, 그 산업 안에서 **좋은 회사이면서 현재 가격이 싼 회사**를 찾는 개인용 가치투자 스캐너입니다.

> 자동 매수/매도 기능은 없습니다. 주문 API를 사용하지 않습니다.

## v0.8 핵심 변경

### 1. 대형주 편향 완화
이전 버전은 관련기업을 시가총액 순으로 놓고 상위 종목부터 분석해 삼성전자·SK하이닉스 같은 대형주가 분석대상에 과도하게 포함될 수 있었습니다.

v0.8은 섹터 구성기업이 많을 때 **대·중·소형주 구간을 고르게 최대 72개 추출**합니다. 절대 매출액과 절대 영업이익 규모는 Quality 점수에 넣지 않습니다.

### 2. Quality와 Value를 분리

**Quality 100점**
- 매출 추세/CAGR: 30
- 영업이익 흑자 지속/증가/CAGR: 20
- 부채비율: 20
- 유보율: 10
- ROE: 10
- 영업이익률: 10

**Value 100점**
- 기계적 적정가 대비 할인여력: 30
- 52주 최저~최고 구간에서의 현재 가격 위치: 20
- PBR/ROE 섹터 상대순위: 20
- PER 섹터 상대순위: 15
- PBR 섹터 상대순위: 10
- 이익수익률(E/P): 5

최종 기본점수:

```text
FF 저평가 우량점수 = Quality 45% + Value 55%
```

증권사 목표주가는 KIS 국내주식 종목투자의견 API에서 최근 값을 확인하고 **최대 +4점 보조가점**만 줍니다. 커버리지가 많은 대형주가 자동으로 유리해지지 않도록 핵심 Value 100점에는 필수항목으로 넣지 않습니다.

### 3. FF 참고 적정가
단일 공식 적정주가가 존재한다고 가정하지 않습니다. 아래 계산값 중 사용 가능한 값의 중앙값을 `FF 참고 적정가`로 표시합니다.

- Graham 참고가: `sqrt(22.5 × EPS × BPS)`
- 동일 섹터 중앙 PER × EPS
- 동일 섹터 중앙 `(PBR / ROE)` × 기업 ROE × BPS

모델이 1개면 신뢰도 낮음, 2개면 보통, 3개면 높음으로 표시합니다. 이는 기업가치의 확정값이 아니라 후보 비교용 기계적 추정치입니다.

### 4. 52주 최저가 근접에 가치함정 방지장치
52주 최저가에 가깝다는 이유만으로 고득점하지 않습니다.

- Quality가 낮으면 52주 저가 점수를 크게 축소
- ROE가 0 이하이면 감점
- 영업이익 흑자 지속성이 부족하면 감점
- 부채비율 200% 이상이면 가치함정 경고
- 최근 3년 매출 감소 시 가치함정 경고

따라서 `싼 주식`보다 `좋은 기업이 싼 가격에 있는지`를 우선합니다.

### 5. KIS에서 추가 활용하는 데이터
기존 API Key 그대로 사용합니다. 별도 Secret은 필요하지 않습니다.

현재가 API에서 다음을 같이 사용합니다.
- PER / PBR
- EPS / BPS
- 52주 최고가 / 최저가 및 일자
- 현재가

상위 후보는 국내주식 종목투자의견 API를 추가 호출해 최근 목표주가를 보조검증합니다.

## 기존 기능 유지

- KIS 산업/업종 추세: MA20/60/120, 기울기, 20/60/120일 모멘텀
- 정확한 산업-기업 매핑
- KRX KOSPI/KOSDAQ 시장데이터 및 종목기본정보 보조
- 외국인·기관 누적 순매수 / 지속매집 상세분석
- 3개년/4분기 실적
- 유보율 / 부채비율 / ROE
- 종목명·영문명 자동검색
- Npay 증권 PC/모바일 자동 연결
- DART / ECOS 연결

## 필요한 Cloudflare Secrets

기존과 동일합니다.

```text
APP_ACCESS_KEY
DART_API_KEY
KIS_APP_KEY
KIS_APP_SECRET
KRX_AUTH_KEY
ECOS_API_KEY
```

새 API Key는 없습니다.

## 주의

- FF 참고 적정가와 점수는 종목을 자동 추천하거나 수익을 보장하는 값이 아닙니다.
- PER은 이익이 음수인 기업에서는 의미가 약하므로 적자기업에 PER 저평가 가점을 주지 않습니다.
- PBR은 ROE와 같이 봅니다. 낮은 PBR만으로 저평가라고 판단하지 않습니다.
- 52주 최저가 근접은 가격 메리트일 수도 있지만 사업 악화의 결과일 수도 있으므로 Quality 조건과 함께 평가합니다.
