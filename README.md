# FF Value Hunter v0.2

GitHub + Cloudflare Workers에서 동작하는 **가치투자 기업분석 도구**입니다.
자동매수/자동매도, 호가창 주문 기능은 포함하지 않습니다.

## v0.2 핵심 보완

- Cloudflare Runtime 변수/Secret이 실제 배포본에서 감지되는지 `/api/config-status`로 먼저 진단
- `keep_vars: true` 적용: GitHub/Wrangler 재배포 시 Dashboard 변수 보존
- Cloudflare Secret 6개를 필수값으로 선언
- KIS OAuth 토큰 동시발급 방지: 여러 API를 동시에 읽어도 토큰은 한 번만 발급
- KIS 재무 API 공식 파라미터 표기 반영
- 한 종목 분석 시 아래 상세영역을 **기본 닫힘 → 클릭 시 펼침** 방식으로 추가
  - 주가 차트 + MA20/60/120
  - 외국인·기관 수급 상세
  - 최근 3년 매출액/영업이익
  - 최근 4개 분기 매출액/영업이익
  - 유보율/부채비율/ROE
  - DART 기업정보
- 일부 KIS 부가 데이터가 실패해도 가능한 데이터는 계속 표시하고 실패 항목만 안내

# 1. 이번 오류의 가장 중요한 해결 순서

Cloudflare Dashboard에서 변수가 화면에 보이더라도 **현재 배포 중인 Worker 버전에 반영되지 않으면** 앱에서는 Missing으로 보일 수 있습니다.

## 먼저 기존 Worker에서 아래 작업

`Settings → Variables and Secrets`

아래 6개를 **모두 Secret 타입**으로 맞추는 것을 권장합니다.

```text
APP_ACCESS_KEY
DART_API_KEY
ECOS_API_KEY
KIS_APP_KEY
KIS_APP_SECRET
KRX_AUTH_KEY
```

현재 `Text`로 되어 있는 `APP_ACCESS_KEY`, `KIS_APP_KEY`도 Secret으로 바꾸세요.
값은 기존에 발급/설정한 값을 그대로 다시 넣으면 됩니다.

### 매우 중요

변수 편집 후 **Save만 하지 말고 Deploy를 눌러야 합니다.**

그 다음 v0.2 코드를 GitHub에 올리고 Cloudflare 자동배포가 끝날 때까지 기다립니다.

# 2. GitHub에 올리기

ZIP 압축을 푼 뒤 루트에 아래 구조가 바로 보여야 합니다.

```text

```

기존 저장소를 사용한다면 v0.1 파일을 v0.2 파일로 교체하고 commit/push 하면 됩니다.

# 3. Cloudflare Build 설정

```text
Production branch: main
Build command: 비워도 됨
Deploy command: npx wrangler deploy
Root directory: /
```

`wrangler.jsonc`에는 다음이 포함되어 있습니다.

```json
"keep_vars": true
```

또한 아래 6개 Secret을 필수로 선언했습니다. 누락되면 배포 단계에서 바로 알려주므로, 배포는 됐지만 앱에서 뒤늦게 Missing이 뜨는 상황을 줄입니다.

# 4. 앱에서 연결 점검

1. 사이트 접속
2. `APP_ACCESS_KEY` 입력
3. `적용`
4. `전체 연결 점검`

v0.2는 API를 바로 호출하기 전에 현재 Worker가 어떤 바인딩을 감지했는지 검사합니다.

정상이라면:

```text
OpenDART       정상
한국투자 KIS    정상
KRX            정상
한국은행 ECOS   정상
```

누락이 있으면 화면 상단에 누락된 변수 이름을 직접 보여줍니다.

# 6. 수급 가점 철학

하루 순매수가 아니라 **지속적인 외국인/기관 매집**에 가점을 둡니다.

```text
외국인 5일 누적 순매수           +5
외국인 20일 누적 순매수         +10
외국인 30일 누적 순매수         +10
외국인 20일 중 순매수 12일+     +10
외국인 연속 순매수 3일+          +5
외국인 보유비율 상승             +10

기관 5일 누적 순매수             +5
기관 20일 누적 순매수           +10
기관 30일 누적 순매수           +10
기관 20일 중 순매수 12일+       +10
기관 연속 순매수 3일+            +5

외국인+기관 20일 모두 누적 순매수 +5
동반 순매수 20일 중 8일+         +5
```

기관의 실제 보유주식수 시계열은 현재 사용 중인 KIS 투자자 API에서 직접 제공되지 않기 때문에 **기관 누적 순매수**를 보유 확대의 대용지표로 사용합니다.

# 7. 재무 데이터 표시 단위

v0.2에서는 KIS 손익계산서의 `sale_account`, `bsop_prti`, `thtr_ntin` 값을 임의로 원/백만원/억원으로 변환하지 않고 **API 원자료 숫자를 그대로 표시**합니다.

데이터 단위를 검증한 뒤 다음 버전에서 `억원/조원` 자동표기까지 고정할 예정입니다. 잘못된 단위를 단정해 표시하지 않기 위한 조치입니다.

# 8. 보안

실제 API 키를 GitHub 코드에 넣지 마세요.

```js
// 금지
const KIS_APP_SECRET = "실제키";
```

Cloudflare Secret으로만 관리합니다.

로컬 테스트가 필요하면 `.dev.vars.example`을 복사해 `.dev.vars`를 만들되 `.dev.vars`는 Git에 올라가지 않도록 `.gitignore`에 포함되어 있습니다.
